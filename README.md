# 观澜命理 · Lan.Destiny

> **看见你的内在结构，找到当下更清晰的方向**  
> 一份基于东方时间模型的个人结构说明书与行为能量指南。去玄学黑话、纯前端离线计算、注重隐私、设计启发于自然标本美学。

---

## 🌿 项目亮点

- **去玄学黑话，转译为现代心理与行为能量光谱**  
  将传统干支十神与五行量化转译为五维行为能量（生长力 / 表达力 / 承载力 / 决断力 / 洞察力），不给宿命论断语，只提供可落地的生活与职场观察。
- **三源互证：生肖 × 星座 × 五维光谱**  
  把大众最熟悉的两个坐标（年柱生肖、太阳星座）与整盘五维光谱翻译到同一套行为语言后再比对，给出「三方共振 / 两源同向 / 双轨互补 / 一源锚定 / 期待与电量错位 / 视角分化」六种结构判断。生肖同时按 **立春** 与 **春节** 两种口径核对，落在换年边界时会明确说明差异，并声明以年柱（立春）口径为准。
- **分享落地页：链接直接落到那一章的试读**  
  场景目录每一行都支持 `?s=self|career|relationship|confusion`（也认 `事业` / `关系` / `迷茫` 等中文别名）：打开后自动展开该场景试读、在行首标注「来自分享」、把页面标题改成「事业方向试读」，并让试读里的 CTA 直接带着这一章进入表单。每张试读卡都有「复制这一章的链接」，报告里的「复制摘要」也会附上当前场景的落地链接。
  **分享海报自带二维码**：海报底部新增一条二维码带（画布 1080×1880），右侧 320px 白卡内是 33×33 模块的二维码，编码 `?s=<当前场景>`；左侧写明「扫码看这一章的试读」并给出可手输的短地址。二维码由仓库内 `static/qr.js` 离线生成（byte 模式，版本 1–6，纠错 M/L），无第三方依赖、不联网；超出容量则降级为纯文字。
- **零输入速览，先看后填**  
  首页支持不填生辰直接选生肖与星座，先看两套体系的行为倾向是否同向，再用「补齐生辰」进入完整说明书——把生肖/星座变成获客入口而不是独立功能。
- **册页式首页：目录 → 试读 → 章节**  
  场景选择不再是四张等权卡片，而是四行「目录行」（汉字序号 + 一句描述 + 指向报告真实章节的页码），点开可先读一页示例再补生辰；「你将获得」改成 8 章目录 + 可点击的示例页，目录与内容一一对应。首屏标本纸（斜置 + 胶带 + 朱砂印）与竖排脊标负责「册子」的气质。
- **分钟级出生时间 + 真太阳时校准**  
  支持 0–23 时 / 0–59 分与出生地经度（**345 个城市，按省份分组并支持关键词搜索**，也可直接手填经度覆盖）。按「经度差 × 4 分钟 + 均时差」换算真太阳时，处理跨日与子时边界，并在依据层写明换算过程；「大概时辰」模式因两小时窗口内偏移方向不确定，明确不启用校准。
- **年运 / 月运 / 90 天行动窗口**  
  把当前与下一个流年、未来 6 个流月换算成「与日主的十神关系」，据此判定推进 / 补给 / 承压窗口，并把未来 90 天切成 3 个动作窗口给出具体动作。全部由干支关系推导，不做吉凶预测。
- **报告先说结论，细节折叠（可读性整改）**  
  正文默认只露出每章结论段与关键图表，其余收进「展开细读」；页面顶部是 8 章贴顶目录，点按即跳转，卡尾有「回到章节目录」。同一结论不再重复出现在多章（整改前阶段节奏整句出现 3 次、协作内耗长句 2 次、标杆交付动作 3 处）；十神 / 干支 / 真太阳时等术语全部收进「依据」折叠页，正文改用五个直白维度名与「主攻手 / 太阳型 / 协作消耗」这类日常说法。30 秒摘要压成「你是谁 / 现在该做 / 别做」三句（长版解释进折叠层），手机端报告从约 13 屏降到约 7.5 屏，首屏就能看到这三句与 8 章目录；顶栏按钮改为两列网格不再与标题抢位。装饰性 emoji 从 8 种收敛到 4 个语义符号（✦ 长板 / ⚠ 风险 / ✔ 该做 / ✖ 别做），去掉英文 badge「PERSONAL STRUCTURE REPORT」，14 天实验的 `P1/P2/P3` 药丸改为「第一步 / 第二步 / 第三步」，并删除「核心画像」里与 30 秒摘要同义的两段（情境交叉校准、力量调和）。
- **专业版六项按性质分组，标签带白话副标题**  
  八字 / 紫微 / 合婚 归入「看你的命盘（需要出生信息）」，梅花 / 六爻 / 奇门 归入「问一件具体的事（需要起卦或时间点）」，每个标签下面一行白话（你的底层结构 / 同一份命的另一种画法 / 看你们俩合不合拍 / 看一件事，快问快答 / 看这件事的另一层细节 / 挑时机和方位）。侧栏写明运行条件：这六项都要本机后端（`run.bat` + `127.0.0.1:8000`），公网上点了只会报错；「看白话词典」可直达词汇抽屉。
  **五项解读真读盘（不再是模板）**：紫微/合婚/梅花/六爻/奇门 的白话解读会解析引擎输出再翻译——紫微读命宫主星、身宫、生年四化落宫、官禄/财帛/夫妻宫与当前大限；合婚读双方日干生克、夫妻宫与年支的合冲害、五行互补；梅花读本卦/互卦/变卦与体用关系；六爻读世应六亲、动静与旬空；奇门读值符值使、八门落宫方位与格局（含「五不遇时」这类硬提示）。解析失败自动回落到原来的名词解释模板，不会报错。
- **生成后的确认首屏：先说三句，再给报告**  
  提交生辰后不是直接甩一份长报告，而是先给 3 条「行为+场景」的断言，逐条问「就是我 / 不太像」。点「不太像」会当场换一条（每条最多换两次）；走完给一张「你认领的自己」，确认结果落成报告顶部的小卡，再进原报告。随时可「跳过，直接看报告」。断言从五维光谱（最强/最弱维度）与当前场景（了解自己/事业/关系/迷茫）里取，不是通用话术；跳过则不渲染小卡。
- **100% 浏览器本地离线计算，0 数据上传**  
  内置天文节气定月、JDN 定日柱与真太阳时校准算法，所有生辰运算完全在本地客户端运行，极致尊重个人隐私。
- **四大场景深度拆解与 14 天行动实验**  
  - ⚡ **01 了解自己**：看见优势、惯性与精力消耗点（止损 / 微调 / 补给）
  - 💼 **02 事业方向**：理解工作节奏、协作解耦与变化倾向（破局 / 解耦 / 沉淀）
  - 🤝 **03 关系模式**：观察表达方式、边界与内在需求（边界 / 连接 / 滋养）
  - 🧭 **04 走出迷茫**：整理此刻更值得优先关注的方向（止损 / 最小验证 / 资产锚定）
  - 四个场景共用同一份命盘事实，但**章节顺序、30 秒摘要口径、情境三问、事业/关系/14 天实验三章内容**按场景重写；「优势与精力模式」按场景重排五维（self 长板优先 / career 按「能不能换成结果」/ relationship 按「对方最先感知到什么」/ confusion 漏能优先），五维分数与百分比始终不变。
  - 「三源互证」按场景换比对重点：self 问「这套自我描述自洽吗」、career 问「工作上该靠哪条通道立身」、relationship 问「对方最先感知到的你」、confusion 问「当下的卡点，三源能解释吗」，并在三张证据卡里高亮对应来源；生肖/星座/五维的映射与光谱结果四场景完全一致。
  - 「年运与 90 天节奏」按场景展开主窗口：self 保留三段全貌；career 只展开「最适合发起与交付」的一段、relationship 只展开「最适合把话说开（补给窗口）」的一段、confusion 只展开「最早可用的最小验证」一段，其余两段压成一行备查，并各自给出「这一段该做 / 这一段避开」；流年、流月表与三段窗口划分本身不变。
  - 「事业与工作方式」「关系中的自己」两章四场景各有侧重补充段：self 走自检（耗电点 / 默认脚本）、career 走职场（协同 vs 攻坚、沟通成本）、relationship 走协作边界、confusion 走「先别换赛道的最小验证 / 关系里的耗电点」。
- **三层信息架构（Progressive Disclosure）**  
  - **Level 1**：30 秒速览说明书核心要点
  - **Level 2**：深度图文拆解与 14 天实验清单
  - **Level 3**：底层数据依据与使用边界（默认折叠，提供理性推导逻辑）
- **Canvas 2x 高清植物标本风海报**  
  支持一键生成 1080×1560 高清分享海报，包含结构光谱、行动建议与专属植物印章，支持一键下载。
- **双模式架构**  
  - **大众版**：个人结构说明书、场景化测评与行动指引
  - **专业工作台**：覆盖八字、紫微、合婚、梅花、六爻、奇门 6 大体系，Bento Grid 专业布局与命书导出

## 🎨 设计系统 (Design System)

- **色调与材质**：星巴克四级绿色阶（`#006241` / `#00754A` / `#1E3932` / `#d4e9e2`）搭配暖米白纸质底色（`#f2f0eb`）与金棕（`#cba258`），营造沉静自然的植物标本感。
- **排版系统**：标题采用经典宋体/衬线体（Lora / Iowan Old Style），正文采用现代清晰的无衬线体（Inter / PingFang SC），阅读舒适克制。
- **手感与微动效**：严格遵循 WCAG 2.1 AA 标准，提供完整的 `:focus-visible` 焦点环、平滑过渡动效与 `prefers-reduced-motion` 无障碍适配。

## 📐 数据口径（三源互证）

| 来源 | 取法 | 说明 |
|------|------|------|
| 时间 | 北京时间 + 出生地经度 | 精确到分钟时可校准：时差 = (经度 − 120) × 4 分 + 均时差；跨日会同步调整日柱，子时按 00:00 换日柱（晚子时） |
| 生肖 | 年柱地支 | 与八字年柱同源，按 **立春** 换年；同时按 **春节**（大众习惯）核对，两者不一致时在报告中显式说明 |
| 星座 | 公历出生月日 | 仅太阳星座，不含出生时刻与上升星座 |
| 五维光谱 | 四柱五行力量加权 | 与既有报告同一套计算，不做二次推断 |
| 年运/月运 | 流年流月干支 | 立春换年、节气分月；十神分组由地支五行与日主的生克关系推导；冲合仅比对日支与年支 |

三者一致只说明当前结构在不同表述体系中稳定，不构成预测；口径不一致时以年柱（立春）为准，并说明差异只影响生肖标签。

## 🚀 快速启动

本项目为纯前端驱动的轻量化现代 Web 应用，零重度构建依赖，开箱即用：

```bash
# 启动本地服务
python server.py
```

在浏览器中打开：
```
http://127.0.0.1:8000/
```

### 环境变量（可选）

| 变量 | 作用 | 默认 |
|------|------|------|
| `BAZI_SKILL_DIR` | 专业工作台使用的命理脚本目录（含 `scripts/paipan.py` 等） | `~/.claude/skills/bazi-mingli` |
| `BAZI_PYTHON` | 运行脚本的 Python 解释器 | 启动服务时所用的解释器 |

消费者模式（个人结构说明书、三源互证、年运与 90 天节奏）不依赖上述任何一项，纯浏览器离线即可使用；专业工作台缺少脚本目录时会返回明确的提示，而不是静默失败。

## 📱 手机使用专业版

专业版要跑 Python 排盘引擎，公网静态托管带不动，所以只能在**你这台电脑**上跑。想让手机也用，走局域网：

1. 双击 **`run-lan.bat`**（不是 `run.bat`）。它会以 `--host 0.0.0.0` 启动，并打印本机的局域网地址；
2. 电脑浏览器打开 `http://127.0.0.1:8000`，进「专业模式」——侧栏会出现**「手机也能进专业版」**的二维码；
3. 手机连**同一个 WiFi**，扫码即可（地址形如 `http://192.168.x.x:8000`）；
4. 用的时候别关那个黑窗口——它就是服务器。

排错：

- 手机打不开 → 先确认手机和电脑在同一个 WiFi（公司/酒店网络常有「客户端隔离」，会挡住）；
- 还是打不开 → Windows 防火墙要放行 Python 的入站（首次运行时会弹窗，勾「专用/公用网络」）；当前网络位置是「公用」时更容易被挡；
- 想确认服务状态 → 手机浏览器打开 `http://<局域网IP>:8000/api/health`，看 `pro_mode` 是否为 `true`、`lan_urls` 是否列出你的局域网地址；
- 二维码面板只在电脑上显示（手机上显示没有意义）；服务连上时侧栏状态条会多一句「（本机服务已连接）」。
